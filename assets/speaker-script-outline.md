# Speaker Script Outline

## 文档结构 / Document Structure

```
一、封面
   - 提案标题 + 副标题 + 英文 Tagline
   - 提案方名称 + 版本号 + 日期
   - 预计口播时长

二、使用说明
   - 节点结构解释
   - 现场使用流程

三、逐页口播稿（按源文档节点顺序）
   每个节点包含：
   - 【对应展示内容】
   - 【可直接朗读的主稿】
   - 【点睛 Insight】
   - 【❓ 追问】
   - 【↪ 转场】
   - 【⚠ 主持提示】(可选)

四、销售收网
   - 聚焦核心问题
   - 确认业务后果
   - 量化不行动代价
   - MVP假设与下一步
   - 分级承诺阶梯
   - 三件事收网

五、分支追问
   - 品牌类
   - 线索与转化类
   - 转化率与复购类
   - 协同数据类

六、高频异议处理

七、会前数据与口径核验清单

八、提案人一页速记
```
